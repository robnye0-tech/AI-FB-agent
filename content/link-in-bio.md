# Link in Bio

Instagram doesn't allow clickable links in captions or carousel slides —
only one link in the profile bio. This file is the source of truth for
that link: paste its contents into whichever link-in-bio tool you use
(Linktree, or Durable's built-in page builder, or a plain landing page),
and keep the bio's link pointed at that page.

Every time a post uses a live affiliate link (see
`content/data/affiliate-links.json`), the daily draft generator adds or
updates that tool's entry below, so this list only ever contains tools
that have actually appeared in a post with a working affiliate link —
never the full 20-tool catalog.
